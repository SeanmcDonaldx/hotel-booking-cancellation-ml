# Predicting Hotel Booking Cancellations

This project looks at whether information available about a hotel booking can be used to predict if the booking will be cancelled.

The dataset used is the Hotel Booking Demand dataset, which contains booking data from a resort hotel and a city hotel in Portugal.

## Setup

The project was completed using Python in Jupyter Notebook.

The main packages used are:
- pandas
- scikit-learn

The dataset file `hotel_bookings.csv` should be placed in the same folder as the notebook.

## Running the Project

Open `01_data_audit.ipynb` in Jupyter Notebook and run the cells in order from top to bottom.

The notebook loads the dataset, carries out the data audit and cleaning, prepares the data for machine learning and runs a simple baseline model.
